1. 생산 흐름 관련
공정 순서(process_order) : 라우팅(앞뒤 공정 연결) 관리
표준 작업 시간(std_time) : 작업자 투입 시간, 생산 계획에 필요
산출물/투입물(input/output material) : 어떤 자재가 들어오고 나가는지

2. 품질/검사 관련
검사 기준(inspection_criteria) : 치수, 허용 오차, 검사 방식
불량 코드/불량 유형(defect_code) : 해당 공정에서 발생할 수 있는 불량 유형

3. 설비/작업자 관리
주 설비(main_equipment_id), 보조 설비(optional_equipment_id)
작업자 수(required_worker_count) : 한 공정 수행에 필요한 인원수

4. 관리 및 추적성
공정 코드(process_code) : 외부 시스템(ERP/PLM) 연계용
상태(is_active) : 현재 사용 여부 (중단된 공정 관리용)
