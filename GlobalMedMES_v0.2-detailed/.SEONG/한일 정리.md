KPI-기록 로직 작성(실시간, 일일)
실시간 = WorkOrder를 기반으로 작성되고 있으며 새로운 퍼포먼스를 작성 했을시 해당 퍼포먼스를 기준으로 해서 수율, 불량율, 시간당 생산량, OEE(설비종합효율)를 계산해서 저장함

일일 = 매일 일정 시간이 되었을때 작동하도록 스케쥴러를 작성해 뒀으며 01:00시에 작동하여 전날 00시 부터 24시 까지의 정보를 종합하여 KPI의 수율 등을 계산하여 저장함

작업지시가 P(계획)에서 R(작동)로 변할때 조건 확인 
해당 작업지시가 지정한 설비에 작업자가 지정되어 있는지 확인,
해당 설비에 배정된 작업자가 해당 설비를 다룰 수 있는 교육 또는 자격증이 있는지 확인, 
해당 설비에 배정된 작업자가 해당 공정을 할 수 있는 교육 또는 자격증이 있는지 확인

시프트 직원 배정 로직
시프트 캘린더를 통해 원하는 날짜와 설비를 넣으면 해당 설비에 대한 시프트가 생성됨
예 : 2025-09-25, 설비-1 ->2025-09-25 설비-1 주간조, 설비-1 전반야, 설비-1 후반야
이렇게 만들어진 설비 시프트의 아이디와 직원의 아이디를 같이 넣으면 직원이 배정됨
또한 하나의 설비 시프트에 여러명의 직원이 함께 배정될 수도 있음

KPI 비가동 시간 계산 로직(KPI가 고장등 예상외의 정지를 계산)
OEE를 계산하는데 필요한 로직으로 KPI의 비가동 시간을 계산함 
비가동 시간이란 작업시간 동안 설비가 동작하지 않은 총 시간을 말함

비가동 시간 계산은 실적을 통하여 작업의 처음의 시작 시간과 마지막 종료 시간을 구하고 이 시간을 총 작업 시간으로 계산하여 저장함
총 작업 시간에 계획된 비가동 시간을 뺀 만큼을 계획된 작업 시간으로 저장
계획된 작업 시간에 계획되지 않은 작업 시간을 뺴서 실제 작업시간을 구하여 거기에 수율과 함께 계산을해 OEE를 구해서 저장함

설비 상세 조회
설비의 아이디를 통해 해당 설비를 상세 조회함
받아오는 항목은

설비 아이디, 설비 명, 워크센터 네임, 상태이름(RUN), 
작업지시(있을시), 제작 품목 이름, 제작 수량, 목표 수량
현재 작업자 목록, 현재 시프트(주간, 전반야, 후반야), 현재 시프트 시작 시간, 현재 시프트 종료 시간, 
해당 설비를 가동하는데 필요한 자격증 목록, 
설비에 연결된 공정 정보(이름, 설명)

이정도를 받아옴


공정 목록
공정 아이디, 공정 이름, 공정 설명을 받아옴

상세 조회
공정 아이디를 통해 해당 공정의
공정 아이디, 공정 이름, 공정 설명, 공정의 설비 목록, 공정에 필요한 자격증, 마지막 수정일, 마지막 수정자를 받아옴

공정 작성
공정의 이름과 설명, 필요한 자격증을 입력하면 해당 정보를 바탕으로 새로운 공정을 작성함

공정 수정
공정 아이디와 공정의 수정할 내용(공정명, 공정 설명, 필요한 자격증)을 적으면 해당 정보를 바탕으로 공정이 수정됨

직원 목록 조회
직원 이름, 직원 번호, 직원이 사용할 수 있는 설비, 직원이 할 수 있는 공정을 조회함
