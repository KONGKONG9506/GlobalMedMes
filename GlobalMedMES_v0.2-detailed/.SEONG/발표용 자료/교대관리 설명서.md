달력 생성과 교대 목록 2개의 창이 있음

달력생성 창에선

필터를 통해 원하는 설비, 원하는 작업장, 원하는 날짜 사이의 내용을 필터링 가능함

일정 생성을 누르면 교대 일정 생성 입력창이 나오고 날짜와 설비를 설정하고 생성 버튼을 누르면 해당 설비의 작업일정 3걔(주간, 전반야, 후반야)가 생성됨

그리고 이후 원하는 작업일정에 배치를 누르면 직원을 배치할 수 있는 입력창이 나오고 
직원을 선택하고 배치를 누르면 해당 일정에 직원이 배치됨

교대 목록에서는 배치된 일정 목록을 볼 수 있으며

교대일, 교대조, 설비, 작업장, 작업자 이름(1명), 배치된 작업자 수, 작업 시작 시간, 작업 종료 시간(교대 예정 시간)을 볼 수 있음
