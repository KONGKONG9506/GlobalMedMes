1.Specification(줄여서 Specs)은 Spring Data JPA에서 제공하는 동적 쿼리(Dynamic Query) 기술.

고급 ORM 설계 패턴

if문 없이도 다양한 필터 조합이 가능해서, 유연하고 깔끔한 동적 검색 API

specification의 장점
가독성 향상: 복잡한 if문 대신 메서드 체이닝으로 조건 구성
유지보수 용이: 조건을 메서드 단위로 분리하여 재사용 가능
조합 가능성: .and(), .or() 등으로 동적 쿼리 조합
JPA와 완벽 호환: Entity 기반으로 안전한 타입 추론
QueryDSL 대체 가능: QueryDSL 설정이 복잡할 때 가벼운 대안으로 활용

2.Idempotency & 중복 방지 설계

중복된 지시번호가 있을 경우 예외 발생 → 멱등성(idempotent) 설계.
생산지시 API를 여러 번 호출해도 중복 데이터가 발생하지 않도록 하는 안정화 로직.

3.1트랜잭션 일관성 관리 (@Transactional)

모든 주요 메서드가 @Transactional로 감싸져 있음.

비즈니스 로직 내에서 여러 Repository 호출이 하나의 트랜잭션으로 묶임.

+트랜잭션이란 데이터베이스에 저장하는 도중 예상치 못한 오류가 발생했을때 실행을 취소함 = 모든 작업이 반드시 성공하거나 성공하지 않거나
